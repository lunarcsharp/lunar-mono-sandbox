MonoSandbox

MonoSandbox is a mod for the virtual reality game Gorilla Tag which introduces a sandbox-based menu inspired by Gary's Mod.
Why use MonoSandbox?

     simplistic menu which makes for easy interaction
     variety of different items with unique mechanics
      polished experience used by hundreds of players
